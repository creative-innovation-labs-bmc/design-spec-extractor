# Project brief

## Description

A browser-based toolkit for measuring Illustrator and PDF website references and exporting an explicit implementation specification for coding agents.

## Build brief

Purpose:
Create the permanent GitHub home for the Design Spec Extractor already developed in this conversation.

Users:
Fooch and collaborators converting Illustrator or PDF website designs into measurable implementation specifications.

Main features:
Import image and PDF references, normalise source-to-CSS scale, mark design regions, record typography and colour tokens, compare generated screenshots against the reference, and export a structured AI handoff package.

Constraints:
Local-first browser processing, Australian English, noindex by default, static GitHub Pages deployment, no API keys in client-side code.
